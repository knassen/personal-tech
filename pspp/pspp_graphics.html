PSPP Graphics: Examples and Notes

PSPP has limited built‑in graphics, so this page shows how to create plots from PSPP data using both PSPP syntax and external tools such as GNUPLOT. These examples include residual plots and other diagnostics commonly used in regression analysis. Also other types of plots PSPP can make for other purposes.

How to Make a Scatterplot of predicted vs residuals.

Here is an example of plotting residuals and predicted values from a linear regression. Residuals should be more or less randomly distributed. There should not be patterns in residuals. That's what you are looking for.

Scatterplots can be found in the PSPPIRE Data Editor menu Graphs-> Scatterplot.

Data:

│  y  │ x1 │ x2 │RES1│PRED1│
├─────┼────┼────┼────┼─────┤
│10.00│1.00│4.10│-.20│10.20│
│12.00│2.00│5.00│ .20│11.80│
│13.00│3.00│6.20│-.07│13.07│
│15.00│4.00│7.10│ .33│14.67│
│16.00│5.00│8.00│-.27│16.27│
╰─────┴────┴────┴────┴─────╯

Code:

** Use regression output variables (pred and resid) to check data.
GRAPH
  /SCATTERPLOT = pred1 WITH res1.

Output:

All we see is a cloud of points and there is no trend or pattern. This is what we'd like to see from residuals: a random scatter with no pattern. With only 5 points, the plot is naturally sparse, but it still shows no systematic pattern (but note it's easy to be fooled by a few points).

Note: psppire outputs the entire output window, not individual plots. One way to save a plot for documentation or reports, is to use your system’s screenshot tool to capture just the graphic from the Output window.

Note: PSPP accepts the SPSS BIVAR keyword in scatterplots for compatibility, but it has no effect on the plot. PSPP always produces a simple bivariate scatterplot.

See Also: PSPP Inferential and Modeling Procedures which has the Linear Regression that produced this plot data.

Further Graphing with GNUPLOT using PSPP Data

Gnuplot is a free plotting program. It can be used on Windows and Linux/Unix to produce plots. See: Gnuplot Demos and Gnuplot Documentation.

Saving the linear regression residuals and predicted values as CSV data from the PSPP REGRESSION procedure allows us to get the data into gnuplot easily.

Program

set datafile separator ","                                                                                              

set terminal pngcairo size 400,400
set output "C:/pspp/residuals2.png"
unset key

set xlabel "Predicted"
set ylabel "Residuals"
set title "Residuals vs Predicted Values"

plot "C:/pspp/regression.csv" using 5:4 every ::1 with points pt 7 ps 1.2 lc rgb "#3366cc" title "Residuals"

This reads the 4th and 5th variables from the CSV file (Residuals on the Y-axis and Predicted on the X-axis). The rgb setting sets the point color, and set title sets the plot title. You can adjust the plot size on the set terminal line. The every ::1 option skips the first line of the CSV file. every is a row selector. The remaining options set the point size, point type, color.

Note, by default, gnuplot puts in an extra plot point to show what the plot symbol is. unset key will remove that point.

The resulting plot looks like this:

A Q–Q plot compares the sample residuals to the theoretical normal distribution. If the residuals follow a straight line, they are approximately normal. Curvature or S‑shapes indicate departures from normality.

Gnuplot Code

set datafile separator ","
set terminal pngcairo size 800,600
set output "C:/pspp/qqplot.png"
unset key

set xlabel "Theoretical Quantiles"
set ylabel "Sample Residuals"
set title "Normal Q-Q Plot of Residuals"

stats "C:/pspp/regression.csv" using 4 nooutput

# Safe row number function for CSV files
row(n) = n + 1

plot "C:/pspp/regression.csv" using \
    (invnorm((row($0) - 0.5) / STATS_records)):4 every ::1 \
    with points pt 7 ps 1.2 lc rgb "#3366cc"

Output

Since this was a small regression example, the plot doesn't show many points.

Using PSPP's EXAMINE Command for Normality Diagnostic Plots

PSPP's EXAMINE command has a /PLOT subcommand that can do several data plots, include a Normal Q-Q plot and a detrended normal Q-Q plot. It also includes the Shapiro-Wilk statistic.

This example will use the same Auto-MPG data used for the above example(s).

Code

GET FILE="regression2.sav".

LIST.

EXAMINE 
  /VARIABLES=res1
  /PLOT NPPLOT.

Note: because I wanted to save the plots for use in this page, I ran this example from a unix command line using command line pspp. psppire will also work, but getting the graphics out is a few more steps. EXAMINE gives a case summary first. This program is reading the residuals (RES1) from the regression model. n=392 is correct and there are no missing values, which is expected.

The two plots produced are noted next. They are the Q-Q plot and the detrended Q-Q plot.

Q-Q plot of the residuals.

De-trended Q-Q plot of the residuals.

The de-trended Q-Q plot shows an issue with normality. The data are obviously skewed. Whether this is enough to bias your model is a judgement you'll need to make, and that gets easier as you get more experience with data.

Finally, the Shapiro-Wilk test of normality result is given. In this case, the test statistic is .97 and p-value is 1.72E-006, which is tiny and much less then .05. Therefore we rejected the null hypothesis that the residuals are normally-distributed. Statistically this indicates non-normality.

Three Panel Gnuplot Diagnostics

This example creates 3 diagnostic plots and then combines them into a three-panel layout. The three plots are: a normal Q-Q plot, a plot of residuals vs. predicted values, and a scale-location plot. It also uses the Auto-MPG data set which gives us 392 points to plot.

Code

set datafile separator ","
set terminal pngcairo size 1200,900
set output "diagnostics3.png"

set multiplot layout 3,1 title "Regression Diagnostics"

##############################
# 1. Normal Q-Q Plot
##############################
set xlabel "Theoretical Quantiles"
set ylabel "Sample Residuals"
set title "Normal Q-Q Plot"
unset key

stats "regression2.csv" using 10 nooutput
row(n) = n + 1

plot "regression2.csv" using \
    (invnorm((row($0) - 0.5) / STATS_records)):10 every ::1 \
    with points pt 7 ps 1.2 lc rgb "#3366cc"

##############################
# 2. Residuals vs Predicted
##############################
set xlabel "Predicted Values"
set ylabel "Residuals"
set title "Residuals vs Predicted"
unset key

plot "regression2.csv" using 11:10 \
    with points pt 7 ps 1 lc rgb "#cc6633"

##############################
# 3. Scale-Location Plot
##############################
set xlabel "Predicted Values"
set ylabel "Sqrt(|Residual|)"
set title "Scale-Location Plot"
unset key

plot "regression2.csv" using 11:(sqrt(abs($10))) \
    with points pt 7 ps 1 lc rgb "#669933"

unset multiplot

Output
